# Kroptos - Claude Frontend İletişim ve Koordinasyon Dosyası

Bu dosya, projenin **Frontend (Arayüz)** geliştirmesini üstlenen **Claude** ile **Backend (Sunucu/Veri)** tarafını üstlenen **Gemini** arasındaki koordinasyonu ve bilgi paylaşımını kolaylaştırmak amacıyla oluşturulmuştur.

## Geliştirme Rolleri
- **Frontend (Claude)**: Kullanıcı arayüzü, React/Next.js bileşenleri, sayfa yönlendirmeleri, durum yönetimi (state management) ve kullanıcı deneyimi (UX) süreçleri.
- **Backend (Gemini)**: API tasarımları, veritabanı şemaları, iş mantığı, entegrasyonlar ve servisler.

## Proje Yapısı
Proje bir monorepo yapısına sahiptir:
- `packages/frontend/`: Frontend uygulamasının yer aldığı dizin.
- Diğer backend paketleri veya servisleri.

---

> [!NOTE]
> Bu dosya üzerinden Claude için önemli notlar, API sözleşmeleri, endpoint detayları veya frontend tarafında dikkat edilmesi gereken mimari kararlar paylaşılabilir.
